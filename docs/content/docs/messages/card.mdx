---
title: Card
description: Present a grouped block of content.
---

Card groups media, a caption, metadata, and an optional action.

## Usage

```js
import "oreui-web/styles.css";
```

```html
<article class="ore-card">
  <div class="ore-card-media">
    <img src="/world.webp" alt="A village beside a river" />
    <div class="ore-card-overlay-bottom-start card-tag-group">
      <span class="ore-tag" data-variant="informative" data-outlined
        >Local</span
      >
      <span class="ore-tag" data-variant="notice" data-outlined>New</span>
    </div>
    <span class="ore-card-overlay-top-end" aria-hidden="true">
      <ore-icon
        ><svg viewBox="0 0 8 8">
          <path
            fill="currentColor"
            d="M1 2h1v1H1zm1 1h1v1H2zm1 1h1v1H3zm1 1h1v1H4zm1-1h1v1H5zm1-1h1v1H6z"
          /></svg
      ></ore-icon>
    </span>
  </div>
  <div class="ore-card-body">
    <div class="ore-card-caption">
      <div class="ore-card-title">Survival World</div>
      <div class="ore-card-description">Last played today</div>
    </div>
    <span class="ore-card-meta">1.21</span>
  </div>
</article>
```

```css
.card-tag-group {
  display: flex;
  gap: var(--ore-card-unit);
}
```

## Overlays

Place labels over media with the overlay classes.

```html
<div class="ore-card-media">
  <img src="/world.webp" alt="A forest village" />
  <span class="ore-tag ore-card-overlay-top-start">New</span>
</div>
```

## Public classes

| Class                            | Purpose                     |
| -------------------------------- | --------------------------- |
| `.ore-card`                      | Card root                   |
| `.ore-card-media`                | 16:9 media area             |
| `.ore-card-body`                 | Caption and action row      |
| `.ore-card-caption`              | Title and description group |
| `.ore-card-title`                | Primary label               |
| `.ore-card-description`          | Supporting text             |
| `.ore-card-meta`                 | Short trailing metadata     |
| `.ore-card-action`               | Trailing Icon Button        |
| `.ore-card-overlay-top-start`    | Top-start media overlay     |
| `.ore-card-overlay-bottom-start` | Bottom-start media overlay  |
| `.ore-card-overlay-top-end`      | Top-end media overlay       |

## CSS variables

| Variable                 | Purpose                 |
| ------------------------ | ----------------------- |
| `--ore-card-unit`        | Base size unit          |
| `--ore-card-border`      | Outer and media border  |
| `--ore-card-background`  | Card body background    |
| `--ore-card-highlight`   | Card body highlight     |
| `--ore-card-shadow`      | Card body shadow        |
| `--ore-card-foreground`  | Title and content color |
| `--ore-card-description` | Description text color  |
