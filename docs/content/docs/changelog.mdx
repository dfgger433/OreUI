## 0.x

### Unreleased

#### Fixed

- Scrollbar: clamp vertical and horizontal overlay thumbs to their track length on short tracks, preventing negative travel.
- Scrollbar: keep controller initialization and cleanup inside the owned Vanilla runtime lifecycle; targeted acceptance passed on real documentation pages and Firefox host paths.

#### Documentation

- Scrollbar: document the Firefox overlay feature checks and the native `scrollbar-color` fallback.
- Docs: disable build-time remote Markdown image size probing so Shields badges remain in the rendered pages without requiring network access during the build.

### 0.0.1

#### Added

- Button: add more native arguments, including link, href, target, rel, download props, loading state, prefix/suffix slots
- Textarea: add textarea component:
  - based on textfield, but supports multiple lines of content
  - supports auto complete, text wrap, rows, spellcheck, etc.add docs for textarea

```html
<ore-textarea
  name="description"
  label="World description"
  placeholder="Describe your world"
  rows="4"
></ore-textarea>
```

- Slider: add range mode with two arguments: value-start (number) & range (boolean)

### 0.0.0

The first public release.

#### Added

- Basics:
  - Typography, Colors, Icons
  - CSS variable override support
  - TailwindCSS and PandaCSS customization support
- Core ([`oreui-web`](https://www.npmjs.com/package/oreui-web)), added 26 new components:
  - Layout: Container, Divider.
  - Button: Button, Icon Button, Tab Button
  - Controls: Checkbox, Dropdown, Radio, Radio Group, Slider, Switch, Textfield, Toggles
  - Navigation: Navbar, Tab Bar, Scrollbar.
  - Message: Accordion, Card, Modal, Table, Tag, Toast, Tooltip
  - Loading: Progress Bar, Progress Ring, Spinner
- Vanilla DOM core package for ordinary web documents and Firefox browser hosts.
- [Figma file](https://www.figma.com/@oreui_web).
- Documentation:
  - Vanilla component examples
  - English and Simplified Chinese documentation
  - LLM support
- Runtime:
  - Vanilla DOM core with CSS-first styling and explicit runtime lifecycle
