---

## Usage

```html
<fieldset class="ore-radio-group">
  <legend>World type</legend>
  <label>
    <input type="radio" name="world" value="survival" checked />
    Survival
  </label>
  <label>
    <input type="radio" name="world" value="creative" />
    Creative
  </label>
  <label>
    <input type="radio" name="world" value="hardcore" disabled />
    Hardcore
  </label>
</fieldset>
```

## Behavior

The native `fieldset` groups related radio inputs, and `.ore-radio-group` provides spacing.
For more information, see [Radio](../radio).

## Accessibility

Use a `legend` to name the group. All child options should share a `name`.
For more information, see [Radio](../radio#accessibility).
