## 0.x

### 未发布

#### 修复

- Scrollbar：将短轨道上的垂直和水平覆盖层滑块限制在轨道长度内，避免产生负的可移动距离。
- Scrollbar：将 controller 的初始化和清理保持在受管理的 Vanilla 运行时生命周期内；真实文档页和 Firefox 宿主路径的定向验收已通过。

#### 文档

- Scrollbar：补充 Firefox 覆盖层的特性检测条件，以及回退到原生 `scrollbar-color` 滚动条的说明。
- 文档站：禁用构建期远程 Markdown 图片尺寸探测，使 Shields 徽章保留在渲染页面中，同时不要求构建时联网。

### 0.0.1

#### 新增

- Button：增加更多原生属性，包括 link、href、target、rel、download 属性，以及 loading 状态、prefix/suffix 插槽
- Textarea：新增 textarea 组件：
  - 基于 textfield，支持多行内容
  - 支持自动补全、文本换行、行数、拼写检查等；新增 textarea 文档

```html
<ore-textarea
  name="description"
  label="World description"
  placeholder="Describe your world"
  rows="4"
></ore-textarea>
```

- Slider：新增范围模式，包含两个参数：value-start (number) 和 range (boolean)

### 0.0.0

首个公开版本。

#### 新增

- 基础：
  - 字体、颜色、图标
  - 支持覆盖 CSS 变量
  - 支持使用 TailwindCSS 和 PandaCSS 自定义样式
- 核心包（[`oreui-web`](https://www.npmjs.com/package/oreui-web)），新增 26 个组件：
  - 布局：Container、Divider
  - 按钮：Button、Icon Button、Tab Button
  - 控件：Checkbox、Dropdown、Radio、Radio Group、Slider、Switch、Textfield、Toggles
  - 导航：Navbar、Tab Bar、Scrollbar
  - 信息：Accordion、Card、Modal、Table、Tag、Toast、Tooltip
  - 加载：Progress Bar、Progress Ring、Spinner
- Vanilla DOM 核心包，面向普通 Web 文档和 Firefox 浏览器宿主。
- [Figma 设计文件](https://www.figma.com/@oreui_web)。
- 文档：
  - Vanilla 组件示例
  - 支持英文和简体中文文档
  - 支持 LLM
- 依赖：
  - [`lit`](https://www.npmjs.com/package/lit)
