OreUI is an unofficial fan-made component library that brings Minecraft's Ore UI design system to your web projects.

Its 25+ components provide framework-independent DOM behavior and styling for semantic HTML.

### Features

- **Vanilla core**: Framework-independent DOM APIs for ordinary web documents and Firefox browser hosts
- **CSS-first**: Semantic HTML receives OreUI styling and behavior
- **Explicit lifecycle**: Create and destroy an owned runtime when the host lifecycle requires it
- **Fully customizable**: Customize using CSS variables, TailwindCSS, PandaCSS and properties
- **Accessibility**: Semantic HTML, keyboard support, focus management, and ARIA
