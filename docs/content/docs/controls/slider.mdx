## Usage

```js
import { createOreUIRuntime } from "oreui-web/runtime";

const runtime = createOreUIRuntime(document);
runtime.init();
```

```html
<input
  class="ore-slider"
  type="range"
  name="distance"
  min="2"
  max="32"
  step="1"
  value="12"
  aria-label="Render distance"
/>
```

## Variants

```html
<input type="range" value="40" aria-label="Volume" />
<input type="range" data-variant="segmented" value="40" aria-label="Volume" />
```

## Events

The native range input dispatches `input` while its value changes and `change` when the interaction is committed. Read `valueAsNumber` for a numeric value. `name`, form submission, reset, disabled fieldsets, and keyboard behavior use the browser's native implementation.

## API

Slider uses the native `HTMLInputElement` API. OreUI adds these visual data attributes:

| Attribute          | Type                                                                                         | Default        |
| ------------------ | -------------------------------------------------------------------------------------------- | -------------- |
| `data-color`       | `"primary" \| "secondary" \| "destructive" \| "dungeons" \| "legends" \| "realms" \| "gold"` | `"primary"`    |
| `data-orientation` | `"horizontal" \| "vertical"`                                                                 | `"horizontal"` |
| `data-variant`     | `"default" \| "segmented"`                                                                   | `"default"`    |

## Accessibility

Add an accessible name with a visible `<label>` or `aria-label`. Slider preserves the native range input's pointer, touch, keyboard, form, disabled, and reset behavior. When using the vertical visual orientation, also set `aria-orientation="vertical"`.
