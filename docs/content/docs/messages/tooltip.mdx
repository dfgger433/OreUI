title: Tooltip
description: Show short hint information.
---

Tooltip adds a short description to a hovered control.

## Usage

```js
import { createOreUIRuntime } from "oreui-web/runtime";

const runtime = createOreUIRuntime(document);
runtime.init();
```

```html
<span class="ore-tooltip" data-side="top">
  <button class="ore-tooltip-trigger" type="button">Copy</button>
  <div class="ore-tooltip-content">
    Create a copy of this world
    <span class="ore-tooltip-arrow" aria-hidden="true"></span>
  </div>
</span>
```

## Placement

Use `data-side="top"`, `"right"`, `"bottom"`, or `"left"` in native HTML. Set the same side with the `data-side` attribute. Position updates while the page scrolls or resizes.

## Delay

`data-delay` is the time in milliseconds before the tooltip opens. Default: `500`.

```html
<span class="ore-tooltip" data-delay="200">...</span>
```

## Events

`oreui:openchange` fires after the open state changes. Its `detail` is the new boolean state.
Use the native `toggle` event.

## API

| Native attribute    | Type                                     | Default |
| ------------------- | ---------------------------------------- | ------- |
| `data-default-open` | `boolean`                                | `false` |
| `data-delay`        | `number`                                 | `500`   |
| `data-open`         | `boolean`                                | unset   |
| `data-side`         | `"top" \| "right" \| "bottom" \| "left"` | `"top"` |

## Public classes

| Class                  | Purpose                          |
| ---------------------- | -------------------------------- |
| `.ore-tooltip-trigger` | Element described by the tooltip |
| `.ore-tooltip-content` | Popover content                  |
| `.ore-tooltip-arrow`   | Directional arrow                |

## CSS variables

| Variable                    | Purpose                  |
| --------------------------- | ------------------------ |
| `--ore-tooltip-unit`        | Base size unit           |
| `--ore-tooltip-corner-size` | Cut corner size          |
| `--ore-tooltip-background`  | Tooltip background color |
| `--ore-tooltip-border`      | Tooltip and arrow border |
| `--ore-tooltip-foreground`  | Tooltip text color       |

## Accessibility

Tooltip connects its trigger and content with `aria-describedby` and closes on pointer leave or `Esc`.
