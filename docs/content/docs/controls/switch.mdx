title: Switch
description: Turn on or off.

## Usage

```html
<label>
  <input
    class="ore-switch"
    type="checkbox"
    role="switch"
    name="autosave"
    value="enabled"
    data-variant="icons"
  />
  Enable autosave
</label>
```

## Forms

Checked values are included in `FormData`, and reset restores the initial state.

## Events

The native input dispatches `input` and `change` events after its checked state changes.

## Attributes

Switch uses the native checkbox attributes `checked`, `disabled`, `name`, `required`, and `value`. Add the `ore-switch` class and `role="switch"` for switch semantics. OreUI options use `data-color` and `data-variant="icons"`.

| Variable                               | Purpose                   |

| `--ore-switch-unit`                    | Base size unit            |

| `--ore-switch-icon`                    | Thumb icon color          |

## Accessibility

The native checkbox provides form and keyboard behavior, while `role="switch"` exposes switch semantics. Use a label to describe the control.
