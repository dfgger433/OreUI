## Usage

```js
import { createOreUIRuntime } from "oreui-web/runtime";

const runtime = createOreUIRuntime(document);
runtime.init();
```

```html
<div class="ore-table ore-scrollbar" data-variant="striped">
  <table>
    <caption>
      Available worlds
    </caption>
    <thead>
      <tr>
        <th scope="col">World</th>
        <th scope="col">Players</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <th scope="row">Mountains</th>
        <td>4 / 10</td>
      </tr>
      <tr>
        <th scope="row">Village</th>
        <td>8 / 20</td>
      </tr>
    </tbody>
  </table>
</div>
```

## Sorting

Put a button with `.ore-table-sort` inside a header with `aria-sort`. Its `value` identifies the column.

```html
<th scope="col" aria-sort="none">
  <button class="ore-table-sort" type="button" value="players">
    Players
    <span class="ore-table-sort-indicator" aria-hidden="true"></span>
  </button>
</th>
```

The `sort` event provides the column and the next direction. The data sorting functionality should be provided by your application.

```js
table.addEventListener("sort", (event) => {
  console.log(event.detail.column, event.detail.direction);
});
```

Use the native control events and inspect the current sort state directly.

## API

| Property  | Attribute      | Type                   | Default   |
| --------- | -------------- | ---------------------- | --------- |
| `variant` | `data-variant` | `"plain" \| "striped"` | `"plain"` |

| Event  | Detail                                                                 |
| ------ | ---------------------------------------------------------------------- |
| `sort` | `{ column: string; direction: "none" \| "ascending" \| "descending" }` |

## Public classes

| Class                          | Purpose                             |
| ------------------------------ | ----------------------------------- |
| `.ore-table`                   | Table container and controller root |
| `.ore-table-row-header-column` | Row-header column width             |
| `.ore-table-data-column`       | Data column width                   |
| `.ore-table-corner`            | Empty top-left corner cell          |
| `.ore-table-sort`              | Sortable header button              |
| `.ore-table-sort-indicator`    | Ascending and descending indicator  |

## CSS variables

The horizontally scrollable table also accepts all [Scrollbar CSS variables](../../navigation/scrollbar#css-variables).

| Variable                               | Purpose                          |
| -------------------------------------- | -------------------------------- |
| `--ore-table-unit`                     | Base size unit                   |
| `--ore-table-border`                   | Cell border color                |
| `--ore-table-header-background`        | Header cell background           |
| `--ore-table-row-background`           | Row background                   |
| `--ore-table-row-background-alternate` | Alternate striped row background |
| `--ore-table-foreground`               | Table text color                 |
| `--ore-table-sort-inactive`            | Inactive sort indicator color    |

## Accessibility

Keep the native table structure, add a caption, and use `scope` on headers.  
Sorting updates `aria-sort`. Announce results when there are no changes.
