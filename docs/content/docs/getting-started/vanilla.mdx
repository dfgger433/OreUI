## Install

```bash tab="pnpm"
pnpm add oreui-web
```

```bash tab="yarn"
yarn add oreui-web
```

```bash tab="npm"
npm install oreui-web
```

```bash tab="bun"
bun add oreui-web
```

### Use from CDN

You can use a CDN to avoid installing any dependencies.

```html title="index.html"
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/oreui-web@latest/dist/styles.css"
/>

<button class="ore-button" type="button">Create new world</button>

<script type="module">
  import { createOreUIRuntime } from "https://cdn.jsdelivr.net/npm/oreui-web@latest/dist/runtime.js";

  createOreUIRuntime(document).init();
</script>
```

<Callout type="info">
  In production you should pin an exact version, for example, `oreui-web@0.1.0`.
</Callout>

## Use a component

```js title="script.js"
import "oreui-web/styles.css";
import { createOreUIRuntime } from "oreui-web/runtime";

const runtime = createOreUIRuntime(document);
runtime.init();
```

```html title="index.html"
<button class="ore-button" type="button">Create new world</button>
```

<Callout type="info">
  The root and browser entries are side-effect-free. Use `oreui-web/auto` only
  when you explicitly want document-wide observation; it is not loaded by the
  root import.
</Callout>

## Browser and SSR hosts

The same Vanilla DOM core works in an ordinary web document and in a host-owned `browser.xhtml` document. Pass the document, an element, or a shadow root that your host owns:

```js
import { createOreUIRuntime } from "oreui-web/runtime";

const runtime = createOreUIRuntime(root, { observe: true });
runtime.init();

// Stop observers and restore component state before removing root.
runtime.destroy();
```

The root import is SSR-safe and does not read `document` or install observers during module evaluation. Load `oreui-web/styles.css` under your CSP policy; the core does not inject inline styles or provide a privileged browser channel. AutoConfig, `resource://` mappings, iframe `type="content"`, and other Firefox-specific bootstrap belong in the host integration, not this package. See the [Firefox browser/chrome host example](https://github.com/katorlys/OreUI/blob/main/examples/firefox-browser-chrome-host/README.md) for a path-free integration outline.

## Examples

Forms:

```html title="index.html"
<form id="account">
  <label><input type="checkbox" name="terms" required />Accept terms</label>
  <button type="submit">Continue</button>
</form>
```

Events:

```js title="script.js"
const form = document.querySelector("#account");

form?.addEventListener("submit", (event) => {
  event.preventDefault();
  console.log(new FormData(form).get("terms"));
});
```
