## 用法

```js
import { createOreUIRuntime } from "oreui-web/runtime";

const runtime = createOreUIRuntime(document);
runtime.init();
```

```html
<span class="ore-tooltip" data-side="top">
  <button class="ore-tooltip-trigger" type="button">Copy</button>
  <div class="ore-tooltip-content">
    Create a copy of this world
    <span class="ore-tooltip-arrow" aria-hidden="true"></span>
  </div>
</span>
```

## 位置

原生 HTML 使用 `data-side="top"`、`"right"`、`"bottom"` 或 `"left"`。框架包装层通过 `side` prop 提供相同设置。页面滚动和调整大小时，位置会一起更新。

## 延迟

`data-delay` 是 Tooltip 显示前的等待时间，单位为毫秒。默认值：`500`。

```html
<span class="ore-tooltip" data-delay="200">...</span>
```

## 事件

打开状态变化后会触发 `oreui:openchange`，其 `detail` 是新的 boolean 状态。
请使用原生 `toggle` 事件。

## API

| 原生属性            | 类型                                     | 默认值  |
| ------------------- | ---------------------------------------- | ------- |
| `data-default-open` | `boolean`                                | `false` |
| `data-delay`        | `number`                                 | `500`   |
| `data-open`         | `boolean`                                | 未设置  |
| `data-side`         | `"top" \| "right" \| "bottom" \| "left"` | `"top"` |

## 公开类

| 类                     | 用途                  |
| ---------------------- | --------------------- |
| `.ore-tooltip-trigger` | 由 Tooltip 描述的元素 |
| `.ore-tooltip-content` | 弹出内容              |
| `.ore-tooltip-arrow`   | 方向箭头              |

## CSS 变量

| 变量                        | 用途               |
| --------------------------- | ------------------ |
| `--ore-tooltip-unit`        | 基础尺寸单位       |
| `--ore-tooltip-corner-size` | 切角尺寸           |
| `--ore-tooltip-background`  | Tooltip 背景颜色   |
| `--ore-tooltip-border`      | Tooltip 和箭头边框 |
| `--ore-tooltip-foreground`  | Tooltip 文本颜色   |

## 无障碍

Tooltip 使用 `aria-describedby` 关联触发器与内容，并在指针移出或按下 `Esc` 时关闭。
