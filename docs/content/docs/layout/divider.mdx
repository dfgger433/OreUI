title: Divider

---

## Usage

```js
import "oreui-web/styles.css";
```

```html
<hr class="ore-divider" />
```

Divider fills the available width. Use the `ore-divider` class or ordinary CSS to control its width and surrounding spacing.

## CSS variables

| Variable              | Purpose                 |
| --------------------- | ----------------------- |
| `--ore-divider-unit`  | Thickness of each line  |
| `--ore-divider-dark`  | Color of the upper line |
| `--ore-divider-light` | Color of the lower line |

## Accessibility

The native `<hr>` represents a thematic break and is exposed as a separator by assistive technology. When the line is only used for decoration and does not separate content, set `role="none"`.
