## Usage

```js
import { createOreUIRuntime } from "oreui-web/runtime";

const runtime = createOreUIRuntime(document);
runtime.init();
```

```html

  <form class="ore-modal-content" method="dialog">
    <header class="ore-modal-header">
      <button
        class="ore-modal-header-button"
```

## Open and close

Call the native `showModal()` method to open a modal dialog. A `form[method="dialog"]` closes it without submitting data; the activated submit button's `value` becomes `dialog.returnValue`.

The optional controller also opens a dialog when a button's `data-modal-target` matches its `id`. Use `data-modal-close="value"` only for a close control that cannot be placed in a dialog form.

```js
const modal = document.querySelector("dialog.ore-modal");
modal.showModal();
modal.close("cancel");
```

## Events

Native `close` fires after the dialog closes, and native `cancel` fires when the user requests dismissal with Escape. Read the result from `returnValue`; the optional controller writes `"backdrop"` or `"escape"` for those dismissal paths.

```js
modal.addEventListener("close", () => {
  console.log(modal.returnValue);
});
```

## Native API

| Member          | Purpose                                        |
| --------------- | ---------------------------------------------- |
| `open`          | Reflects whether the dialog is open            |
| `returnValue`   | Value supplied by `close()` or the dialog form |
| `showModal()`   | Opens in the top layer as a modal              |
| `close(value?)` | Closes with an optional return value           |

## Public classes

| Class                      | Purpose                      |
| -------------------------- | ---------------------------- |
| `.ore-modal`               | Native dialog root           |
| `.ore-modal-content`       | Dialog frame                 |
| `.ore-modal-header`        | Title bar                    |
| `.ore-modal-title`         | Accessible dialog title      |
| `.ore-modal-description`   | Accessible supporting text   |
| `.ore-modal-header-button` | Header action                |
| `.modal-form-body`         | Scrollable dark form section |
| `.modal-confirmation`      | Confirmation section         |
| `.modal-actions`           | Dialog action section        |

## Accessibility

The native dialog provides top-layer rendering, focus containment, inert background content, Escape handling, and focus restoration. Supply `aria-labelledby` and, when useful, `aria-describedby`.
