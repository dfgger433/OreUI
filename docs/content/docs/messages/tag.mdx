---
title: Tag
description: Display a single-line label.
---

## Usage

```js
import "oreui-web/styles.css";
```

```html
<span class="ore-tag" data-variant="primary">New</span>
```

## Variants

```html
<span class="ore-tag">Neutral</span>
<span class="ore-tag" data-variant="secondary">Secondary</span>
<span class="ore-tag" data-variant="primary">Primary</span>
<span class="ore-tag" data-variant="informative">Info</span>
<span class="ore-tag" data-variant="notice">Notice</span>
<span class="ore-tag" data-variant="warning">Warning</span>
<span class="ore-tag" data-variant="realms-informative">Realms</span>
```

Add `outlined` to add a visible border to the label.

```html
<span class="ore-tag" data-outlined>Outlined</span>
```

## API

| Configuration | Attribute       | Type                                                                                                      | Default |
| ------------- | --------------- | --------------------------------------------------------------------------------------------------------- | ------- |
| variant       | `data-variant`  | `"neutral" \| "secondary" \| "primary" \| "informative" \| "notice" \| "warning" \| "realms-informative"` | neutral |
| outlined      | `data-outlined` | boolean visual combination                                                                                | off     |

## CSS variables

| Variable               | Purpose          |
| ---------------------- | ---------------- |
| `--ore-tag-unit`       | Base size unit   |
| `--ore-tag-background` | Label background |
| `--ore-tag-foreground` | Label text color |
| `--ore-tag-border`     | Outline color    |
