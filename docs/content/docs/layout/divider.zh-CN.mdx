## 用法

```js
import "oreui-web/styles.css";
```

```html
<hr class="ore-divider" />
```

Divider 默认填满可用宽度。使用 `ore-divider` class 或普通 CSS 控制宽度和周围间距。

## CSS 变量

| 变量                  | 用途         |
| --------------------- | ------------ |
| `--ore-divider-unit`  | 每条线的粗细 |
| `--ore-divider-dark`  | 上方暗线颜色 |
| `--ore-divider-light` | 下方亮线颜色 |

## 无障碍

原生 `<hr>` 表示主题内容分隔，并会被辅助技术识别为 separator。如果仅将其用于装饰用途，不用于内容分隔，应设置 `role="none"`。
