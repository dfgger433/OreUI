## 用法

```js
import { createOreUIRuntime } from "oreui-web/runtime";

const runtime = createOreUIRuntime(document);
runtime.init();
```

```html
<input
  class="ore-slider"
  type="range"
  name="distance"
  min="2"
  max="32"
  step="1"
  value="12"
  aria-label="Render distance"
/>
```

## 事件

原生 range input 的值变化时会触发 `input` 事件，提交交互时会触发 `change` 事件。使用 `valueAsNumber` 读取数值。`name`、表单提交、重置、禁用 fieldset 和键盘行为均由浏览器原生实现。

## API

Slider 使用原生 `HTMLInputElement` API。OreUI 只增加以下视觉 data 属性：

| 属性               | 类型                                                                                         | 默认值         |
| ------------------ | -------------------------------------------------------------------------------------------- | -------------- |
| `data-color`       | `"primary" \| "secondary" \| "destructive" \| "dungeons" \| "legends" \| "realms" \| "gold"` | `"primary"`    |
| `data-orientation` | `"horizontal" \| "vertical"`                                                                 | `"horizontal"` |
| `data-variant`     | `"default" \| "segmented"`                                                                   | `"default"`    |

## CSS 变量

| 变量                                   | 用途           |
| -------------------------------------- | -------------- |
| `--ore-slider-unit`                    | 基础尺寸单位   |
| `--ore-slider-track-border`            | 轨道边框颜色   |
| `--ore-slider-active-range-background` | 激活范围背景   |
| `--ore-slider-active-range-highlight`  | 激活范围高光   |
| `--ore-slider-track-background`        | 未激活轨道背景 |
| `--ore-slider-track-highlight`         | 未激活轨道高光 |
| `--ore-slider-thumb-background`        | 滑块背景       |
| `--ore-slider-thumb-highlight`         | 滑块高光       |
| `--ore-slider-thumb-shadow`            | 滑块阴影       |
| `--ore-slider-thumb-border`            | 滑块边框颜色   |

## 无障碍

使用可见 `<label>` 或 `aria-label` 设置无障碍名称。Slider 保留原生 range input 的指针、触摸、键盘、表单、禁用和重置行为。使用竖直视觉方向时，还应设置 `aria-orientation="vertical"`。
