## 用法

```js
import { createOreUIRuntime } from "oreui-web/runtime";

const runtime = createOreUIRuntime(document);
runtime.init();
```

```html
<div class="ore-table ore-scrollbar" data-variant="striped">
  <table>
    <caption>
      Available worlds
    </caption>
    <thead>
      <tr>
        <th scope="col">World</th>
        <th scope="col">Players</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <th scope="row">Mountains</th>
        <td>4 / 10</td>
      </tr>
      <tr>
        <th scope="row">Village</th>
        <td>8 / 20</td>
      </tr>
    </tbody>
  </table>
</div>
```

## 排序

在带有 `aria-sort` 的表头中放置一个带有 `.ore-table-sort` 的按钮。其 `value` 值用于标识列。

```html
<th scope="col" aria-sort="none">
  <button class="ore-table-sort" type="button" value="players">
    Players
    <span class="ore-table-sort-indicator" aria-hidden="true"></span>
  </button>
</th>
```

`sort` 事件提供列和下一个排序方向。数据排序功能应由应用程序提供。

```js
table.addEventListener("sort", (event) => {
  console.log(event.detail.column, event.detail.direction);
});
```

请使用原生控件事件，并直接读取当前排序状态。

## API

| Prop      | 属性           | 类型                   | 默认值    |
| --------- | -------------- | ---------------------- | --------- |
| `variant` | `data-variant` | `"plain" \| "striped"` | `"plain"` |

| 事件   | 详细信息                                                               |
| ------ | ---------------------------------------------------------------------- |
| `sort` | `{ column: string; direction: "none" \| "ascending" \| "descending" }` |

## 公开类

| 类                             | 用途                     |
| ------------------------------ | ------------------------ |
| `.ore-table`                   | 表格容器与 controller 根 |
| `.ore-table-row-header-column` | 行标题列宽度             |
| `.ore-table-data-column`       | 数据列宽度               |
| `.ore-table-corner`            | 左上角的空单元格         |
| `.ore-table-sort`              | 可排序的表头按钮         |
| `.ore-table-sort-indicator`    | 升序和降序指示器         |

## CSS 变量

可水平滚动的表格也可使用所有的 [Scrollbar CSS 变量](../../navigation/scrollbar#css-变量)。

| 变量                                   | 用途                 |
| -------------------------------------- | -------------------- |
| `--ore-table-unit`                     | 基础尺寸单位         |
| `--ore-table-border`                   | 单元格边框颜色       |
| `--ore-table-header-background`        | 表头单元格背景       |
| `--ore-table-row-background`           | 行背景               |
| `--ore-table-row-background-alternate` | 条纹表格交替行背景   |
| `--ore-table-foreground`               | 表格文本颜色         |
| `--ore-table-sort-inactive`            | 未激活排序指示器颜色 |

## 无障碍

保留原生表格结构、添加表格标题，并在表头上使用 `scope`。  
排序会更新 `aria-sort`。当排序后顺序没有变化时，请提示用户重新排序后的结果。
