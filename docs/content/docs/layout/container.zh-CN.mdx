title: Container 容器
description: 在容器中组合内容
---

## 用法

```js
import { createOreUIRuntime } from "oreui-web/runtime";

const runtime = createOreUIRuntime(document);
runtime.init();
```

```html
<div class="ore-container" data-variant="dark">
  <h2>World settings</h2>
  <p>Choose how players join your world.</p>
</div>
```

## 变体

```html
<div class="ore-container" data-variant="dark">Dark surface</div>
<div class="ore-container" data-variant="light">Light surface</div>
```

## API

| Prop      | HTML 属性      | 类型                | 默认值   |
| --------- | -------------- | ------------------- | -------- |
| `variant` | `data-variant` | `"dark" \| "light"` | `"dark"` |

## CSS 变量

| 变量                               | 用途                     |
| ---------------------------------- | ------------------------ |
| `--ore-container-unit`             | 基础尺寸单位             |
| `--ore-container-dark-background`  | 深色变体背景颜色         |
| `--ore-container-light-background` | 浅色变体背景颜色         |
| `--ore-container-highlight`        | 顶部和侧边高光颜色       |
| `--ore-container-shadow`           | 底部阴影颜色             |
| `--ore-container-divider`          | 区块之间的分隔线颜色     |
| `--ore-container-foreground`       | 内容文本颜色             |
| `--ore-container-padding`          | 表面边缘与内容之间的间距 |
| `--ore-container-gap`              | 直接子元素之间的间距     |
