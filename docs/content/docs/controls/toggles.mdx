---
title: Toggles
description: Choose from a group of tabs.
---

## Usage

```js
import { createOreUIRuntime } from "oreui-web/runtime";

const runtime = createOreUIRuntime(document);
runtime.init();
```

```html
<div class="ore-toggles" role="tablist" aria-label="Daylight cycle">
  <button class="ore-tab-button" type="button" role="tab" aria-selected="true">
    Day
  </button>
  <button class="ore-tab-button" type="button" role="tab" aria-selected="false">
    Night
  </button>
  <button class="ore-tab-button" type="button" role="tab" aria-selected="false">
    Always
  </button>
</div>
```

## Behavior

Toggles sets `role="tablist"`, lays out its children, and applies the `toggle` palette to direct and nested Tab Buttons.  
For more information, see [Tab Button](../../buttons/tab-button/).

## Accessibility

Give the tab group an accessible name. `Arrow keys` move through enabled options. `Home` and `End` select the first and last option.
