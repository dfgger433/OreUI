---
title: Container
description: Group content inside a container.
---

## Usage

```js
import { createOreUIRuntime } from "oreui-web/runtime";

const runtime = createOreUIRuntime(document);
runtime.init();
```

```html
<div class="ore-container" data-variant="dark">
  <h2>World settings</h2>
  <p>Choose how players join your world.</p>
</div>
```

## Variants

```html
<div class="ore-container" data-variant="dark">Dark surface</div>
<div class="ore-container" data-variant="light">Light surface</div>
```

## API

| Prop      | HTML attribute | Type                | Default  |
| --------- | -------------- | ------------------- | -------- |
| `variant` | `data-variant` | `"dark" \| "light"` | `"dark"` |

## CSS variables

| Variable                           | Purpose                                        |
| ---------------------------------- | ---------------------------------------------- |
| `--ore-container-unit`             | Base size unit                                 |
| `--ore-container-dark-background`  | Dark variant background color                  |
| `--ore-container-light-background` | Light variant background color                 |
| `--ore-container-highlight`        | Top and side highlight color                   |
| `--ore-container-shadow`           | Bottom shadow color                            |
| `--ore-container-divider`          | Divider color between sections                 |
| `--ore-container-foreground`       | Content text color                             |
| `--ore-container-padding`          | Space between the surface edge and its content |
| `--ore-container-gap`              | Space between direct children                  |
