## 用法

```js
import { createOreUIRuntime } from "oreui-web/runtime";

const runtime = createOreUIRuntime(document);
runtime.init();
```

```html
<progress
  class="ore-progress-bar"
  value="65"
  max="100"
  aria-label="Download progress"
></progress>
```

## 标签

需要可见标签时，使用相邻的 `output`。将它放在进度条之前或之后即可选择标签位置。

```html
<progress
  class="ore-progress-bar"
  value="65"
  max="100"
  aria-labelledby="download-label"
></progress>
<output class="ore-progress-bar-label" id="download-label">65%</output>

<output class="ore-progress-bar-label" data-align="start" id="chunks-label"
  >65 of 100 chunks</output
>
<progress
  class="ore-progress-bar"
  value="65"
  max="100"
  aria-labelledby="chunks-label"
></progress>
```

## API

Progress Bar 接受 HTML `progress` 元素的标准属性，包括 `value` 和 `max`。省略 `value` 可表示不确定进度。

## 公开类

| 类                        | 用途           |
| ------------------------- | -------------- |
| `.ore-progress-bar`       | 原生进度条元素 |
| `.ore-progress-bar-label` | 可选的可见标签 |

## CSS 变量

| 变量                       | 用途             |
| -------------------------- | ---------------- |
| `--ore-progress-bar-unit`  | 基础尺寸单位     |
| `--ore-progress-bar-frame` | 边框和空轨道颜色 |
| `--ore-progress-bar-fill`  | 已填充轨道颜色   |
| `--ore-progress-bar-label` | 标签文本颜色     |

## 无障碍

原生 `progress` 元素提供进度条语义和值信息。使用 `aria-label` 或 `aria-labelledby` 提供无障碍名称，或者用可见的 `output` 提供该名称。
