## API

Icon Button is a native button. It supports standard button attributes, events, form behavior, and focus behavior.

| Property   | Attribute  | Type                            | Default    |
| ---------- | ---------- | ------------------------------- | ---------- |
| `disabled` | `disabled` | `boolean`                       | `false`    |
| `type`     | `type`     | `"button" \|"reset" \|"submit"` | `"submit"` |

## CSS variables

| Variable                         | Purpose                      |
| -------------------------------- | ---------------------------- |
| `--ore-icon-button-unit`         | Base size unit               |
| `--ore-icon-button-background`   | Face background color        |
| `--ore-icon-button-highlight`    | Top highlight color          |
| `--ore-icon-button-shadow-color` | Bottom shadow color          |
| `--ore-icon-button-corner`       | Corner accent color          |
| `--ore-icon-button-border`       | Border color                 |
| `--ore-icon-button-foreground`   | Icon and text color          |
| `--ore-icon-button-place-items`  | Internal grid item alignment |
| `--ore-icon-button-width`        | Button width                 |
| `--ore-icon-button-height`       | Button height                |
| `--ore-icon-button-padding`      | Internal padding             |
| `--ore-icon-button-box-shadow`   | Additional outer box shadow  |

## Accessibility

Add an `aria-label` to describe the action. The icon inside the button should use `aria-hidden="true"`.
