---
title: Spinner
description: Show an indeterminate loading state.
---

## Usage

```js
import { createOreUIRuntime } from "oreui-web/runtime";

const runtime = createOreUIRuntime(document);
runtime.init();
```

```html
<span class="ore-spinner" role="status" aria-label="Loading worlds"></span>
```

## Size and color

Spinner uses the current font size and text color.

```html
<span style="font-size: 2rem; color: #52A535;">
  <span class="ore-spinner" role="status" aria-label="Loading worlds"></span>
</span>
```

## Decorative

Hide the Spinner from assistive technology when nearby text already describes the loading state.

```html
<span class="ore-spinner" aria-hidden="true"></span> <span>Loading worlds</span>
```

## Accessibility

In HTML, provide an `aria-label` that describes the loading state. When it is decorative, use `aria-hidden="true"`.
Animation stops when reduced motion is enabled.
