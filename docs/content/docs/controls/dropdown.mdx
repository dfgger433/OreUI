title: Dropdown
description: Select an option from a menu.
---

## Usage

```js
import { createOreUIRuntime } from "oreui-web/runtime";

const runtime = createOreUIRuntime(document);
runtime.init();
```

```html
<div class="ore-dropdown" data-variant="bordered" data-value="creative">
  <button
    class="ore-button ore-dropdown-trigger"
    type="button"
    data-color="secondary"
  >
    <span class="ore-dropdown-trigger-label">Game mode</span>
  </button>
  <div class="ore-dropdown-menu">
    <button class="ore-dropdown-item" type="button" data-value="survival">
      Survival
    </button>
    <button class="ore-dropdown-item" type="button" data-value="creative">
      Creative
    </button>
    <button class="ore-dropdown-item" type="button" data-value="adventure">
      Adventure
    </button>
    <button
      class="ore-dropdown-item"
      type="button"
      data-value="spectator"
      disabled
    >
      Spectator
    </button>
  </div>
</div>
```

## Variants

`borderless` shows item borders on interaction, while `bordered` keeps them visible.

## Events

| Event    | Detail                                        |
| -------- | --------------------------------------------- |
| `change` | `{ item: HTMLButtonElement; value: string }`  |
| `toggle` | Standard Popover event dispatched by the menu |

Use the native `change` event. Listen for the menu `toggle` event when open state matters.

## API

| Data attribute | Type                         | Default        |
| -------------- | ---------------------------- | -------------- |
| `data-value`   | `string`                     | `""`           |
| `data-variant` | `"bordered" \| "borderless"` | `"borderless"` |

## Public classes

| Class                         | Purpose                             |
| ----------------------------- | ----------------------------------- |
| `.ore-dropdown-trigger`       | Button that opens the menu          |
| `.ore-dropdown-trigger-label` | Text updated from the selected item |
| `.ore-dropdown-menu`          | Popover menu                        |
| `.ore-dropdown-item`          | Selectable menu item                |

## CSS variables

The menu's scrollable area also accepts all [Scrollbar CSS variables](../../navigation/scrollbar#css-variables).

| Variable                               | Purpose                        |
| -------------------------------------- | ------------------------------ |
| `--ore-dropdown-unit`                  | Base size unit                 |
| `--ore-dropdown-menu-background`       | Menu background color          |
| `--ore-dropdown-menu-outline`          | Menu outline color             |
| `--ore-dropdown-item-background`       | Item background                |
| `--ore-dropdown-item-background-hover` | Hovered item background        |
| `--ore-dropdown-item-border`           | Divider color between items    |
| `--ore-dropdown-foreground`            | Item text and icon color       |
| `--ore-dropdown-visible-items`         | Items visible before scrolling |

## Accessibility

Dropdown manages menu roles, selection state, focus, and `Arrow`, `Home`, `End`, `Enter`, `Space`, `Esc`, and `Tab` keys.  
Use native `disabled` on unavailable items.
