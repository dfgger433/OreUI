## Usage

```js
import "oreui-web/styles.css";
```

```html
<label>
  <input class="ore-checkbox" type="checkbox" name="updates" value="yes" />
  Receive updates
</label>
```

## Forms

Checked values are included in `FormData`. Reset restores the initial `checked` state.

```html
<form>
  <label>
    <input
      class="ore-checkbox"
      type="checkbox"
      name="terms"
      value="accepted"
      required
    />
    Accept the terms
  </label>
  <button type="submit">Continue</button>
  <button type="reset" data-color="secondary">Reset</button>
</form>
```

## Events

The native checkbox dispatches `input` and `change` events when its value changes.

## API

Checkbox uses the native `HTMLInputElement` API. Use `checked`, `disabled`, `name`, `required`, and `value` directly; use `data-color` only for the OreUI palette. Native methods such as `checkValidity()` and `reportValidity()` remain available.

## CSS variables

| Variable                                   | Purpose                    |
| ------------------------------------------ | -------------------------- |
| `--ore-checkbox-unit`                      | Base size unit             |
| `--ore-checkbox-background`                | Unchecked background       |
| `--ore-checkbox-highlight`                 | Unchecked highlight        |
| `--ore-checkbox-border`                    | Border color               |
| `--ore-checkbox-indicator`                 | Checkmark color            |
| `--ore-checkbox-active-background`         | Checked background         |
| `--ore-checkbox-active-background-hover`   | Checked hover background   |
| `--ore-checkbox-active-background-pressed` | Checked pressed background |
| `--ore-checkbox-active-highlight`          | Checked highlight          |
| `--ore-checkbox-active-highlight-hover`    | Checked hover highlight    |
| `--ore-checkbox-active-highlight-pressed`  | Checked pressed highlight  |

## Accessibility

The native input provides checkbox semantics, label activation, Space key behavior, form participation, validation, and reset behavior without JavaScript.
