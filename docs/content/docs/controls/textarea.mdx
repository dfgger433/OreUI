## Usage

```js
import "oreui-web/styles.css";
```

```html
<div class="ore-textarea">
  <label class="ore-textarea-label" for="world-description"
    >World description</label
  >
  <span class="ore-textarea-control">
    <textarea
      class="ore-textarea-input"
      id="world-description"
      name="description"
      placeholder="Describe your world"
      rows="4"
    ></textarea>
  </span>
  <span class="ore-textarea-description"
    >Shown on the world selection screen</span
  >
</div>
```

## Resize

Textarea can be resized horizontally and vertically by default, and it can be customized through its public class.

```css
.ore-textarea > .ore-textarea-control > .ore-textarea-input {
  resize: none;
}
```

## Selection and scrolling

The native `<textarea>` directly provides `selectionStart`, `selectionEnd`, `setSelectionRange()`, `scrollTop`, and `focus()`.

```js
const textarea = document.querySelector("textarea");
textarea.focus();
textarea.setSelectionRange(0, 5);
```

## Events

The native textarea dispatches `input` whenever its value changes and `change` when the edit is committed. Its `value` property is the single form state source.

## API

| Property                  | Attribute                 | Type                        | Default         |
| ------------------------- | ------------------------- | --------------------------- | --------------- |
| `autocomplete`            | `autocomplete`            | `string`                    | browser default |
| `disabled`                | `disabled`                | `boolean`                   | `false`         |
| `inputMode`               | `inputmode`               | `string`                    | browser default |
| `maxLength` / `minLength` | `maxlength` / `minlength` | `number`                    | browser default |
| `name`                    | `name`                    | `string`                    | `""`            |
| `placeholder`             | `placeholder`             | `string`                    | `""`            |
| `readonly`                | `readonly`                | `boolean`                   | `false`         |
| `required`                | `required`                | `boolean`                   | `false`         |
| `rows`                    | `rows`                    | `number`                    | `2`             |
| `spellcheck`              | `spellcheck`              | `boolean`                   | browser default |
| `wrap`                    | `wrap`                    | `"hard" \| "off" \| "soft"` | `"soft"`        |

## Public classes

| Class                       | Purpose            |
| --------------------------- | ------------------ |
| `.ore-textarea-label`       | Visible label      |
| `.ore-textarea-control`     | Textarea frame     |
| `.ore-textarea-input`       | Native textarea    |
| `.ore-textarea-description` | Supporting text    |
| `.ore-textarea-error`       | Validation message |

## CSS variables

Textarea exposes the same styling roles as Textfield with the `--ore-textarea-*` prefix, including `background`, `shadow`, `border`, `foreground`, `input-foreground`, `description`, `error`, `focus-ring`, and `caret`.

## Accessibility

Use a visible `label` with a matching `for` and `id`. Associate supporting or error text through `aria-describedby`; use the native `required`, `minlength`, `maxlength`, `readonly`, and `disabled` attributes for their respective states.
